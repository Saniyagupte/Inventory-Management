# Inventory Management System

## Description
An Inventory Management System built using React (frontend) and Node.js (backend) to help manage product stock in a warehouse and perform CRUD operations. The app allows you to add, update, and delete products from the inventory, view stock levels, and manage product categories in a seamless manner.

## Features
- Add, delete, and update products.
- View inventory status and stock levels.

## Technologies Used
- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (for storing product data)
  
## Installation

Follow these steps to get the project up and running on your local machine.

### 1. Clone the Repository
First, clone the repository to your local machine:

git clone https://github.com/Saniyagupte/Inventory-Management.git
cd Inventory-Management

### 2. Install Frontend & Backend Dependencies

cd server
npm install

### 3. Install Frontend Dependencies

cd frontend
npm install

### 4. Start Backend Server 

npm start

### 5. Start Frontend Server 

npm run dev
